# 🐾 PetCare POS & CRM System

> An end-to-end full-stack POS and CRM web application built to digitize and manage daily operations, customer relationships, and transaction workflows for a multi-branch pet care chain generating over **3+ billion VND/month** in revenue.

---

## 🏗️ 1. System Architecture & Tech Stack
The application is structured around a robust client-server and cloud-native architecture:
* **Database Layer:** Relational PostgreSQL hosted on **AWS RDS**, ensuring high availability, data integrity, and secure multi-branch transaction logging.
* **Backend API:** Built with **Python (FastAPI)**, handling business logic, data validation, and secure endpoints.
* **Frontend & Deployment:** Web interface deployed and hosted seamlessly on **Vercel** for rapid client-side access.
* **Version Control:** Managed via **GitHub** with structured branch workflows.

---

## 📊 2. Core Features & Modules
* **Point of Sale (POS):** Real-time transaction processing, service billing, and inventory tracking across multiple branches.
* **Customer Relationship Management (CRM):** Centralized database managing customer profiles, pet details, purchase history, and tier-based tracking.
* **Operational Dashboards:** Provides store managers and leadership with clear visibility into daily revenues, peak operating hours, and top-performing services.
